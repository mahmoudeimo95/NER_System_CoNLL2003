# NER_System_CoNLL2003
Developed an end-to-end NER system using PyTorch and Hugging Face, implementing and comparing LSTM, BiLSTM, BiLSTM-CRF, and DistilBERT models on CoNLL-2003. Evaluated performance using Precision, Recall, and F1-score, and deployed an interactive Gradio app for real-time entity recognition and visualization.
